## 修复配置抽屉/持仓表的 4 个 UI 回归（前端）

用户报 4 个截图问题，逐个用浏览器（Chrome + playwright-core 连系统 Chrome）复现并验证修复：

1. **选中持仓后勾消失 + 表头全选框看不见**：根因是 `generate-mdi-subset.mjs` 只扫源码里手写的 `mdi-*` 字面量，漏掉了 Vuetify 运行时通过别名渲染的内部图标（`checkboxOn=mdi-checkbox-marked`、`checkboxIndeterminate=mdi-minus-box`、排序箭头、下拉箭头等）。修复：脚本 import `vuetify/iconsets/mdi` 的 `aliases`，把全部 mdi- 别名并入扫描集合。图标数 77 → 121。顺带修了 `mdi-swap-horizontal-multiple`（不是合法图标名，批量反手按钮图标空白）→ `mdi-swap-horizontal-bold`；并排除 `mdi-icons.css` 路径的误报。
2. **配置抽屉顶部两个页签被压成一条线、点击整块收起**：ConfigDrawer 的 `.config-drawer__frame` 是 flex 列，`.config-drawer__body` 有 `overflow-y:auto` 但默认 `min-height:auto`，拒绝收缩到内容高度以下，把无 `flex-shrink:0` 的 v-tabs 从 48px 挤到 20px。修复：body 加 `min-height:0`，tabs 加 `flex-shrink:0`。浏览器实测 tabs 高度 20→48。
3/4. **多/空设置里"总价值"输入框与"选币"控件挤在一起**：v-card-text 直接子级表单控件紧凑+outlined 浮动 label 叠压。修复：ConfigDrawer 里给 `.v-card-text > .v-input/.smart-select/.v-btn:not(:last-child)` 加 `margin-bottom:12px`（只作用直接子级，不影响 v-row 内止损/止盈并排栅格）。

验证：`npx vite build` 通过、`vue-tsc --build` 通过、图标生成无 warning、浏览器截图确认页签可见 + 间距正常 + 图标字形有真实 codepoint。

改动文件：`frontend/scripts/generate-mdi-subset.mjs`、`frontend/src/styles/mdi-icons.css`（生成物）、`frontend/src/components/ConfigDrawer.vue`、`frontend/src/components/PositionsTable.vue`。
