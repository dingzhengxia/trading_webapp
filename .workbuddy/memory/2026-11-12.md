## 合并后回测第五轮：找到真优化（ATR 1.5/1R）

- **修正上一轮的错误结论**：leverage=20 时爆仓线在价格反向 4.5–5%，而 300%/20=15% 的止损
  永远到不了。按爆仓线重算，现行配置是 **-16.2%**（此前估 +12.2% 是"止损一定能成交"的假设）。
  教训：回测任何 percent 止损前，必须先算 1/leverage 的爆仓线，越过它就不是风控而是装饰。
- **最优出场**：`signal_exit_mode=atr`、`sl_atr=1.5`、`tp_r=1.0`、`max_bars=6`。
  4h 8 币 180 天：+21.4bp/笔、总 +50.5%、MDD -14%、1931 笔、胜率 55%。
  前半 +12.4bp / 后半 +30.5bp；7/8 币正；持有 4~12 根全为正；成本容错到 30bp。
- **TP 必须 ≤1R**：6/8/12/16/20 根下 TP=1R 恒 +25~30bp，2R 恒负、3R 恒更负。
  这批信号是"走 1 倍风险距离就回头"，不是趋势启动。
- **1h 仍然不值得**：ATR 1R + 立即入场也只有 +6.6bp（4126 笔），16bp 成本归零。
- **ATR 口径的真正价值**：杠杆不再偷偷决定止损宽度（percent 是 ÷leverage）。
  **注意**：`signal_auto_trade_value_usd` 是固定名义金额，杠杆不放大盈亏，只改爆仓距离
  （≈反向 1/L）与占用保证金。20x 的爆仓线 -4.6% 比 ATR 止损还近，所以仍要降到 5x。
- 修了实盘隐患：`_resolve_atr` 原本只读全局 `signal_live_exit_timeframe`，1h 信号会用 4h 的
  ATR（止损宽一倍）。改为自动开仓透传 `_signal_timeframe` 优先。
- 脚本：`final_bt.py`（网格+样本内外）、`validate2.py`（候选验证）、`robust5.py`（平台/成本/逐币）；
  `exit_modes.collect` 增 `atr_pct` 列。文档第 11 节；提交 1a51d10，254 passed。

## 第八轮：GBDT 实验 + 发现回测去重 bug（重大纠错）

- 用户要试 LightGBM。环境已装 lightgbm 4.5.0 / xgboost / sklearn。
- 资源基准（`gbdt_bench.py`，2万行×25特征）：训练 159ms(全核)/537ms(单核)，内存峰值 2MB，
  模型 291KB，单条推理 0.22ms、批量30条 0.45ms。**比一次 Binance API 请求快 500 倍，可忽略。**
- **发现重大 bug**：`exit_modes.collect` 的 dedupe 用 `entry_ts < exit_ts`，
  持有 1 根时 exit_ts == entry_ts → 判定失效；而 res_wide.csv 每条信号复制 3 份（h=1/3/6），
  同一根 K 线的多策略信号被重复计 3~6 次。**修复为 `<=`**。
  - `res_wide.csv` 结构：26052 行 = 方向性信号 2417 条 × 持有期 h(1/3/6)。唯一(币,ts)=2006。
  - 影响：第 5~13 节所有收益数字。ATR 1.5/1R 从 1931 笔 +21.4bp → **1096 笔 +1.5bp**。
  - 被误放行的 218 笔平均 +63bp（同根共振），虚高 10pp。
  - 生产代码不受影响：auto_trader 查交易所真实持仓，不做时间戳比较。
- **修正后真实结果**：4h 全样本 +1.5bp/笔；5-8月 +15.1bp、8-11月 **-13.0bp**；
  月度 -55.7/+33.6/+41.8/-10.3/+0.2/-17.7/-51.4。
- **策略排序反转**：trend_channel_breakout 从 -17.9 → **+11.3bp（最好，126笔）**，
  已恢复进 `signal_auto_trade_strategies` 白名单（此前误移除）。
  其余：rsi_div +2.9、ema_cross +2.2、ma_breakout +0.7、level_breakout -2.8。
- **GBDT 结论：无效**。1096 笔×38 特征，样本外(9月起) IC=0.008，五分组不单调，
  过滤曲线全负。信噪比 1:200（期望 1.5bp vs 单笔标准差 300bp），样本量差一个数量级。
- **多策略共振无独立价值**：单策略 +1.5 / 2个同向 -0.3 / ≥3个 +7.3(47笔,噪声)。
- 教训：① `exit_ts == entry_ts` 是合法状态（持有1根），用时间戳判"占用"必须 `<=`；
  ② 回测输入含重复行时，去重后要用「唯一键数」自检；
  ③ 写新模拟器先逐位复现旧结果再信它。
