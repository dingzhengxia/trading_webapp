## 杠杆（合约倍数）调整支持

- **现状诊断**：后端 `NUMERIC_RANGES['leverage']=(1,125,True)` 白名单与开仓链路
  `_set_leverage_safe_async`（阶梯降级 10/5/2/1）早已支持，唯一缺的是前端 UI；
  且**校准任务（sync-sltp）拿到 leverage 后只用于保证金显示，从不 set_leverage**
  —— payload 里的 leverage 字段一直是死配置。
- **改动 1（ControlPanel.vue）**：「高级执行参数」卡片首位加「合约杠杆倍数」输入
  （min1/max125/suffix x），hint 说明两条生效路径：新开仓直接生效；已有持仓随
  「校准 SL/TP」推送（改杠杆会变清算价）。draft 深拷贝整包 UserSettings，leverage
  自动走 diff 保存，无需改 useDraftSettings。
- **改动 2（trading_service.py `_sync_sltp_task`）**：worker 里先
  `_set_leverage_safe_async`（幂等，同值无副作用）再 set_tp_sl；失败只 warning
  不阻断 SL/TP 同步。防御：payload leverage<=0 时回退 `load_settings()`——
  不能 fallback 到 schema 默认值 1（会把持仓悄悄降到 1x）。
- **生效路径**：改杠杆 → 1.5s 防抖 PATCH → 新开仓按新杠杆；已有持仓需手动点
  「校准 SL/TP」（顺带重挂 SL/TP 条件单，幂等）。
